# chrome-auto-close

## 1.0.1 (2026-09-29)

- changed: Asana rule matches only task and project links, leaving attachments and other Asana pages open
- fixed: Tabs a site opens on the same site, such as an Asana task opened from Asana, no longer close

## 1.0.0 (2026-09-28)

- added: Extension that closes tabs opened on Slack, Zoom, Asana, Discord and Teams links after a 5s default delay
- added: Popup with a close countdown and keep-open button, plus an options page for rules and delays
